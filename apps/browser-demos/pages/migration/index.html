Tab-to-tab machine handover

Start fbDOOM here, watch it live in a second tab, take it over there.

Start fbDOOM in this tab, open this page in a second tab, and watch the same game render live there. Press "Take over" in the watching tab and the running machine freezes, crosses the BroadcastChannel, and continues there from the same frame — the keyboard moves with it, and the tab that handed over keeps watching live. Take it back whenever you like — the machine moves between the tabs as often as you ask, and only the tab that holds it can play.

Connect another computer
Create an invite code on the watching computer, answer it on the running one.

Two tabs on one computer connect by themselves. Another computer must be introduced by hand: one side creates an invite code, the other answers it, and you carry both codes across (chat, e-mail, a shouted dictation). Once connected, the machine mirrors, hands over, and comes back across the network exactly as it does between tabs.

On the watching computer press "Create invite code" and send the code to the computer that runs the game. There, paste it below, press "Answer invite", and send the answer code back. Paste the answer on the watching computer and press "Complete connection".

The page needs a secure context on both computers: serve it over HTTPS, or open Chromium with --unsafely-treat-insecure-origin-as-secure=http://<host-ip>:5401 for LAN testing.
