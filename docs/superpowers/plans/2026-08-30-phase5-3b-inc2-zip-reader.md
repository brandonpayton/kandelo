# Phase 5 Increment 3b.2 — In-kernel ZIP reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Port the read-only ZIP archive reader from the host TypeScript (`host/src/vfs/zip.ts` + `host/src/vfs/package-deferred-tree.ts`) into a new `runtime-core` Rust module, so the in-kernel rootfs overlay can expand deferred lazy-archives (`man.zip`, `node.zip`, …) itself. This is the second slice of the Increment 3b parser migration (after the SFFS reader, 3b.1).

**Architecture:** A self-contained, read-only, `no_std + alloc` module `crates/runtime-core/src/zip.rs` over a borrowed `&[u8]`. It locates the End-Of-Central-Directory record, walks the central directory into a `Vec<ZipEntry>`, and extracts a member's bytes (method 0 = stored copy; method 8 = **raw DEFLATE** via the `miniz_oxide` crate). A `derive_entry` layer maps a member to a VFS node (dir / symlink / regular) mirroring the host `deriveEntry` semantics. Pure library slice — no syscall wiring, no ABI change, no host change; wired to the overlay in a later increment.

**Tech Stack:** Rust (`no_std` on wasm, `std` in tests), `alloc`, `miniz_oxide` (raw inflate). Fixtures generated by the project's canonical Info-ZIP script.

**Spec:** `docs/plans/2026-08-28-phase5-vfs-to-rust.md` (# Increment 3b; slice step 2). **Authoritative reference implementations to PORT (read them):** `host/src/vfs/zip.ts` (parser + extraction) and `host/src/vfs/package-deferred-tree.ts` `deriveEntry` (lines 557-659; entry→VFS mapping). Mode constants: `host/src/generated/abi.ts:456-480`.

## Global Constraints

- **Read-only, no_std + alloc.** Never mutate input; `crates/runtime-core` is `no_std` on wasm (std only in tests); `alloc::vec::Vec`; no `std::` in non-test code. Little-endian throughout.
- **Errno:** `use wasm_posix_shared::Errno;` (as `sffs.rs`/`syscalls.rs` do). Use EINVAL for malformed archives, EIO for a decode failure.
- **Dependency:** add `miniz_oxide = { version = "0.8", default-features = false, features = ["with-alloc"] }` to `crates/runtime-core/Cargo.toml`. It already resolves in the workspace lockfile and builds no_std wasm32 in the kernel release build (verified). Raw DEFLATE (no zlib/gzip wrapper) — use the raw inflate entry point (`miniz_oxide::inflate::decompress_to_vec` decompresses raw deflate; confirm the exact fn/signature in the crate docs and that it takes `&[u8]` and returns `Result<Vec<u8>, _>`).
- **Untrusted input:** every offset/length is validated against the buffer length with checked arithmetic (compute in u64 / `usize::try_from` where a u32 field could exceed the buffer); no panics on any input. Reject: general-purpose bit-flag bit 3 (`gpflag & 0x0008`, data descriptor), Zip64 (any `0xFFFFFFFF` size/offset or Zip64 extra field), compression method ∉ {0,8}, non-UTF-8 or non-round-tripping names, and an inflate whose output ≠ the declared uncompressed size.
- **Test target:** `cargo test -p runtime-core --target "$(rustc -vV | sed -n 's/^host: //p')" zip`. Build check: `cargo build -p kandelo -Z build-std=core,alloc`. Run all cargo/TS via `scripts/dev-shell.sh bash -c '...'`.
- **Commit hygiene:** stage ONLY the files a task creates/edits (`git add <path> …`), NEVER `git add -A`/`.` (the worktree has unrelated untracked noise). Confirm `git status --short` before each commit.
- **Format facts (verbatim from zip.ts + verified against man.zip):** EOCD sig `0x06054b50` (min 22B, scan back up to 65557B for it); entries@EOCD+10 (u16), cdOffset@EOCD+16 (u32). Central header sig `0x02014b50` (46B fixed): version-made-by@+4 (u16; creator_os = `>>8`), gpflag@+8, method@+10, csize@+20, usize@+24, nameLen@+28, extraLen@+30, commentLen@+32, extAttr@+38 (u32; `st_mode = (extAttr >> 16) & 0xffff` when creator_os==3), localOff@+42; name@+46; advance `46+nameLen+extraLen+commentLen`. Local header sig `0x04034b50` (30B fixed): localNameLen@+26, localExtraLen@+28; member data starts at `localOff + 30 + localNameLen + localExtraLen`. Method 0=stored, 8=raw deflate. Mode masks: `S_IFMT=0o170000`, `S_IFLNK=0o120000`, `S_IFREG=0o100000`, `S_IFDIR=0o040000`. `is_dir = name.ends_with('/')`; `is_symlink = creator_os==3 && (st_mode & S_IFMT)==S_IFLNK`; **a symlink's target is its (decompressed) member content.**

### Task 1: Committed tiny ZIP fixture + generator

**Files:** Create `host/scripts/gen-zip-rust-fixture.sh` (wraps the canonical Info-ZIP builder); Create (committed) `crates/runtime-core/src/testdata/tiny.zip`.

**Interfaces — the fixture must contain (every later task asserts against this):**
- `bin/` and `etc/` directories (stored, mode 0o040755).
- `etc/small.txt` = `b"hello\n"` — a STORED member (method 0). Force stored: a tiny/incompressible file.
- `bin/big.txt` = 4096 bytes of `b'a'` — a DEFLATE member (method 8), mode 0o100755 (exec).
- `bin/link` → symlink whose target is `big.txt` (S_IFLNK, target = member content `b"big.txt"`).

- [ ] **Step 1: Write the generator** `host/scripts/gen-zip-rust-fixture.sh`:
```bash
#!/usr/bin/env bash
set -euo pipefail
repo="$(cd "$(dirname "$0")/../.." && pwd)"
tmp="$(mktemp -d)"; trap 'rm -rf "$tmp"' EXIT
mkdir -p "$tmp/bin" "$tmp/etc"
printf 'hello\n' > "$tmp/etc/small.txt"          # tiny -> stored
head -c 4096 /dev/zero | tr '\0' 'a' > "$tmp/bin/big.txt"  # compressible -> deflate
chmod 755 "$tmp/bin/big.txt"
( cd "$tmp/bin" && ln -s big.txt link )          # symlink, target = content "big.txt"
out="$repo/crates/runtime-core/src/testdata/tiny.zip"
mkdir -p "$(dirname "$out")"
bash "$repo/images/vfs/scripts/create-deterministic-zip.sh" "$tmp" "$out"
echo "wrote $out"
```
NOTE: read `images/vfs/scripts/create-deterministic-zip.sh` first to confirm its argument shape (`<stage-dir> <out.zip>`) and adjust if it differs. It uses the system `zip` (Info-ZIP) with `-X -y -6`.

- [ ] **Step 2: Run in dev shell + verify:** `scripts/dev-shell.sh bash -c 'bash host/scripts/gen-zip-rust-fixture.sh'`; then `zipinfo -v crates/runtime-core/src/testdata/tiny.zip` — confirm: `bin/link` is `lrwxrwxrwx … stor` with 7-byte target `big.txt`; `bin/big.txt` is `defN` (deflate); `etc/small.txt` is `stor`; all `3.0 unx`, `gpflag=0`, `extra_len=0`.
