# N1-F5: Real externref reference CAPTURE across fork (all hosts, FLOOR-1)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. **READ FIRST:** `docs/plans/2026-09-05-n1-f5-externref-capture-grounding.md` (the authoritative design map — wire format, symmetry table, per-import evidence, the 7-step breakdown this plan operationalizes), and `docs/plans/2026-09-05-n1-i5-references-grounding.md` (the replay side that is capture's spec). Checkbox steps.

**Goal:** Lift the externref `EOPNOTSUPP` gate so a live `externref` held across `fork()` is captured and reconstructed (identity-preserved) in the child, on native + Node + browser — via FLOOR-1 **production-site provenance recording** (stamp the handle when the externref is minted), NOT the deleted unsound capture-time reverse-lookup.

**Architecture:** The replay/decode side is already built + shared + frozen (`fork_codec`, the module's `fm_ref_*`, `resolve_externref`) and is the spec. Capture is the inverse: the wire *writer* `ReferenceGraphBuilder::intern_externref(handle)` already exists as the decoder's bit-for-bit inverse. The ONLY missing primitive is `live externref → handle`, which cannot be recovered by inspection (unsound; that reverse-lookup was deleted) and must be **recorded at mint time**. So F5 adds a new instrumenter pass wrapping every externref-returning host-import call site with a provenance-recording import, whose host body registers `(value identity → handle)` at mint; capture then does a guaranteed-present lookup + `intern_externref`.

**Tech Stack:** Rust (`crates/fork-instrument`, `crates/shared`, `crates/host-native`), TypeScript (`host/src`), wasmtime 48, Kandelo SDK + `scripts/run-wasm-fork-instrument.sh`.

**Spec:** `docs/plans/2026-09-05-n1-f5-externref-capture-grounding.md` + `docs/fork-reference-support.md`.
